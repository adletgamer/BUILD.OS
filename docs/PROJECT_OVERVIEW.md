# Project overview

## Purpose

BUILD.OS is a cinematic, interactive portfolio that presents a builder's technical capabilities, engineering judgment, leadership, community work and creative identity. It should feel like a coherent digital product rather than a collection of animated portfolio cards.

## Product principles

- Facts first: publish only verified personal and project information.
- Interaction with purpose: motion and 3D explain hierarchy, relationships or state.
- Progressive enhancement: core content remains usable when 3D, animation or advanced input is unavailable.
- Inclusive by default: semantic markup, keyboard access, visible focus and reduced-motion support.
- Responsible performance: defer heavy 3D assets and protect mobile devices from unnecessary work.

## Initial scope

The product includes a cinematic hero, safe interactive terminal, technology universe, project missions, leadership narrative, life telemetry, hidden easter egg and contact section. Sprint 0 provides section anchors and labelled placeholders, without inventing portfolio content.

## Success criteria

- Visitors can understand the builder identity and reach verified work quickly.
- The experience works on desktop, tablet and mobile.
- Core navigation and content work with a keyboard and reduced motion.
- Production builds pass strict type checking, linting and automated tests.
- Deployment uses AWS Amplify Hosting without committed credentials.
