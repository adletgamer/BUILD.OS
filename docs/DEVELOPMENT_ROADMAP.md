# Development roadmap

Every sprint must deliver functional code, executed validation, updated documentation and a Git commit.

| Sprint | Objective | Priority | Exit criteria |
| --- | --- | --- | --- |
| 0 | Repository, audit and foundation | Critical | Governance, architecture, app shell, strict tooling and checks pass |
| 1 | Design system and cinematic 3D hero | Critical | Responsive tokens/components and meaningful R3F hero with graceful fallback |
| 2 | Interactive terminal and command palette | Critical | Safe allowlisted commands, keyboard UX and accessible command palette |
| 3 | Tech Universe, missions and leadership | Critical | Verified structured content and responsive interactive storytelling |
| 4 | Life Telemetry and Easter Egg | High | Consent-aware integrations or placeholders and discoverable hidden interaction |
| 5 | AWS deployment, QA and submission | Critical | Amplify deployment, performance/accessibility QA and submission evidence |

## Dependency order

The design system precedes feature visuals. The command model precedes terminal animation. Verified structured data precedes the Tech Universe and mission views. Deployment begins only after application behavior and content pass QA.

## Sprint 0 deliverables

- Project constitution and initial documentation.
- React/Vite entry point and semantic section shell.
- Approved CSS tokens and responsive breakpoints.
- Strict TypeScript and ESLint configuration.
- Error boundary and reduced-motion utilities.
- Credential-safe environment example and ignore rules.
- Automated lint, test and production build commands.

## Sprint 1.1 delivered

- Local typography for Space Grotesk, Inter and JetBrains Mono.
- Approved design tokens and reusable button, badge and card primitives.
- Minimal five-item navigation, editorial hero, chapter markers and dedicated canvas slot.
- Responsive desktop, tablet and mobile rules with reduced-motion styling.

## Sprint 1.2 delivered

- Procedural R3F Builder Core with a faceted center, independent rings, domain nodes, connections and restrained particles.
- Pointer parallax and proximity response; compact hover and scroll-reveal labels.
- ScrollTrigger driven orbit and domain separation states.
- Lazy canvas loading, bounded DPR, demand rendering and a mobile or reduced-motion CSS fallback.
